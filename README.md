# Yash Meena — Portfolio

Creative editorial portfolio built with Next.js, TypeScript, Framer Motion and Lucide icons.

## Run locally
1. Install Node.js 18.18+.
2. Open a terminal inside this folder.
3. Run `npm install`
4. Run `npm run dev`
5. Open http://localhost:3000

## Current build notes
- The portrait is a temporary synthetic editorial image and should be replaced with a final professional photograph before launch.
